## 💡 Key Metrics & Insights Visualized

The dashboard tracks major retail Key Performance Indicators (KPIs) over a multi-year timeline (2014–2017):

* **High-Level KPIs:** Instant tracking of total business health—generating **$2,297,201 in Sales**, **$286,397 in Net Profit**, and managing **9,994 total Orders** with a minimal return footprint.
* **Sales by Month:** A continuous timeline chart mapping historical growth, revealing seasonal peaks and structural upward trends heading into 2018.
* **Sales by State:** A geographic choropleth map highlighting core markets across the United States to isolate regional revenue centers.
* **Product Drilldown:** Horizontal breakdown ranking performance by **Sub-Category** (showing *Phones* and *Chairs* leading global volume, while *Fasteners* account for lower revenue bands).
* **Customer Lifetime Value:** Leaderboard tracking top-tier revenue drivers like *Sean Miller* and *Tamara Chand*.

## 🛠️ Interactive Features Built-In
* **Metric Switcher Parameter:** Dynamically switch the entire dashboard view between **Profit**, **Sales**, or **Quantity Sold** with a single click.
* **Global Filters:** Cross-filter charts simultaneously using side panels for **Region** (Central, East, South, West), **Customer Segment**, and core **Product Categories**.
* **Temporal Slicers:** Adjust global quarter/year boundaries effortlessly using the interactive timeline slider.

## 💾 Dataset
This project utilizes the localized **Sample - Superstore** dataset. It simulates operational transaction tracking for an e-commerce retail supplier to model real-world business intelligence reporting scenarios.
